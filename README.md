# FitFuel Hub Dynamic Website

This is a front-end dynamic website prototype for FitFuel Hub.

## Dynamic features
- Product search
- Category filters
- Add-to-cart
- Cart persistence using localStorage
- Automatic cart count
- Automatic total calculation
- Meal/product rendering from JavaScript data
- Nutrition recommendation tool
- Responsive mobile design

## To make it a real production website
Connect the front end to:
- MySQL/PostgreSQL database
- Node.js/Express, PHP/Laravel, or another backend
- Customer registration/login
- Admin dashboard
- Real inventory
- Order management
- Payment gateway
- Delivery/order tracking
- Nutritionist appointment system
